# TaskForge 

Aplicação de lista de tarefas desenvolvida com React + TypeScript.

##  Sobre o projeto

O TaskForge é um sistema simples de organização de tarefas, permitindo criar, visualizar e excluir tarefas com data, ajudando no planejamento do dia a dia de forma prática.

##  Funcionalidades

- Adicionar tarefas
- Definir data da tarefa
- Listar tarefas cadastradas
- Excluir tarefas
- Atualização automática da lista

##  Tecnologias utilizadas

- React
- TypeScript
- Axios
- CSS3
- Node.js (backend API)
